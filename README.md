A helper utility to format loot data for my addon [Great Vault Odds](https://github.com/MattZeeX/GreatVaultOdds)

Requires [LFS](https://lunarmodules.github.io/luafilesystem/).

Ensure the `GreatVaultOddsDB` table in your saved variables is empty, and then generate the DB in-game. Copy your `GreatVaultOdds.lua` saved variable file into the `Input` folder in this directory, and then run the bat file. You should be able to find the DB file in the `Sorted Tables` folder in this same directory, sorted to my needs.
