# GreatVaultOdds DB Sorter

A helper utility for formatting loot data generated by my addon Great Vault Odds:
[CurseForge](https://www.curseforge.com/wow/addons/great-vault-odds) and
[GitHub](https://github.com/MattZeeX/GreatVaultOdds).

## Requirements

- Lua
- [LuaFileSystem](https://lunarmodules.github.io/luafilesystem/)

LuaFileSystem is used for directory work: checking whether folders exist, creating
missing folders, and listing files in `Input`. Standard Lua `io`/`os` functions
are still used for reading, writing, and removing files.

## Usage

1. Empty the `GreatVaultOddsDB` table in your saved variables.
2. Generate the database in-game.
3. Copy your `GreatVaultOdds.lua` saved-variable file into the `Input` folder.
4. Run `launch.bat`, or run the script directly:

   ```bat
   lua TableFixAndSort.lua
   ```

5. Find the sorted output in `Sorted Tables`.

By default, the script processes `GreatVaultOddsDB`. To process a different table,
pass the table name as the first argument:

```bat
lua TableFixAndSort.lua SomeOtherTable
```

If the default table name changes permanently, edit `defaultTargetTable` near the
top of `TableFixAndSort.lua`.

## What It Does

For each `.lua` file in `Input`, the script:

1. Finds the target table.
2. Prepares the saved-variable source so Lua can load it by ensuring the table is
   local and returned.
3. Loads the table in memory.
4. Serialises the table with stable sorting rules.
5. Archives the original input file in `Input/Archived Inputs`.
6. Writes the formatted output to `Sorted Tables`.
7. Removes the original input file only after processing succeeds.

If the target table is not found, the file is skipped and left in `Input`. If the
table cannot be loaded, archived, or written, the original input file is not
removed.

## Sorting Rules

Sorting is configured near the top of `TableFixAndSort.lua` in `config.sortRules`.

Current order:

1. Scalar values before nested tables.
2. Prioritised table keys, such as `sources`, before other nested tables.
3. Other nested tables.

Within the same group:

- Numeric keys sort numerically.
- String keys sort alphabetically.
- Mixed key types sort by their string representation.

## Tests

The test runner uses fixed fixture files in `Tests/Fixtures`.

Run:

```bat
lua Tests/run.lua
```

The tests compare generated output against known-good output files and also check
small source-preparation and key-formatting cases.
